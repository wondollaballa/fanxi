# The midcast set stays on until the spell resolves (host/addons/phase.c).  GearSwap waits for
# the server's result packet before aftercast, and the server reads a spell's numbers (Cure
# potency, MAB, Macc, the magic skills) at the instant it lands, so a step, a stance flip, a
# zone/job settle or a plan push must not take the midcast set off while the cast bar is up.
# The pin starts at the server's Magic Start (0x028 category 8, "ca"+school), not at the
# client's action packet, so a refused cast leaves the state free; the same category with
# "sp"+school is the interrupt and ends the pin at once.  Run by tests/phase_cast_test.sh.
