# Job-point coverage

All **220 conditional category rows** are now represented by either a client status,
a modifier, or a direct mechanic.  There are no unclassified category rows left.

Some systems remain approximations rather than full retail simulations:

- Blue Magic Points are exposed as a modifier; there is no spell-set manager.
- Automaton burden/head modes and geomancy/luopan behavior are simplified.
- Bard song potency covers the main families but not every retail modifier.
- Rune Enchantment is represented by a state/modifier.

The static gift table, skill gifts and passive category rows are fully applied.
